# 機能の棚卸（一覧表）

## 1. はじめに

### この一覧の目的

アプリのすべての機能について、「何をするか」「どう動くか」「業務に何をもたらすか」を並べた資料です。本当に必要な機能かを判断するために使います。
この一覧は判断の材料をまとめるだけで、機能を削るかどうかは決めていません。

### 調べ方

- アプリは起動せず、画面の自動クリックもしていません。プログラムと記録（設計判断の記録・変更履歴・作業記録）を読んで調べました。
- 利用の実績は、配布フォルダ（dist）のデータを一時フォルダへ写し、その写しを読み取り専用で開いて数えました。元のファイルには触れていません。
  - 写しの場所：`%TEMP%\claude\c--work-inventory\9cc5a145-9c05-44a3-9dd0-6d37b9be2f8c\scratchpad\inv7`
  - 写しと元のファイルは、3つとも内容が同じことを確かめました（app_settings.json・db\master.db・db\2026-08\inventory.db）。
- 数えたのは、操作履歴（操作するたびに残る記録）、データベースの作成・削除の履歴、各表の件数です。
- 操作履歴に残らない機能は、表の件数から分かるものだけを書き、それ以外は「記録なし」としました。

### データの時点と、読むときの注意

- 2026-10-20（v3.1.0）の時点です。
- 今のデータはテスト用で、使い始めたばかりです。2026-10-19 16:34〜16:37 の数分間に、マスター・計画・実績CSV を取り込んだだけです。
  - マスター：構成基板数・基板丁数・生産面
  - 計画：2ファイル
  - 実績CSV：1ファイル（登録待ちへの取り込みまで）
- 実績の登録は0件です。そのため、「記録が無い」は「要らない」という意味ではありません。
- 検証のために写しの上で操作した分（登録待ちからの登録など）は、写しを捨てたので含まれていません。

### 評価の印

| 印 | 意味 |
|---|---|
| 必要（ほかの機能の前提） | ほかの機能がこれを使っているので、無いと別の機能が動かない |
| 必要（業務で使う） | 毎月の業務の流れの中で使う |
| 要検討 | 理由を書いた上で、要るかどうかを判断していただきたいもの |

## 2. 全体の地図

### メニューの構成

```
ログイン画面 ── ログイン／作業者を登録（新規）
   │
メインメニュー
 ├─ データベース選択（上段）：切り替え／削除／新しいデータベースを作成（前月から未完了分を引き継ぐ）
 ├─ バックアップ／バックアップの呼び出し／マスタデータを他PCから取り込む（管理者のみ）
 ├─ 月次データ（右）
 │    1. 生産計画読込 ……… 計画CSVの取り込み・取り込みの履歴
 │    2. 生産実績入力 ……… 実績の登録・NGの申告
 │         ├─ 実績修正（修正・削除・取り消し）
 │         ├─ 実績レポート（日報・月報）── 仕掛数量抽出
 │         ├─ ロット進捗チェック ── ロット統合
 │         ├─ 日々の引落一覧
 │         └─ 実績CSV取込／実績CSV取込状況 ── 登録待ち一覧（Shift+S・Shift+Q）
 │    3. NG・仕損展開 ……… NGを部品に展開して登録 ── 製品NGレポート／96NGレポート／NG実績修正
 │    4. 仕掛部品展開 ……… 仕掛を部品に展開して登録 ── 仕掛製品レポート／仕掛96レポート／仕掛実績修正
 │    5. 在庫値入力
 │    6. 理論値入力
 │    7. 在庫値出力（在庫差異レポート）
 ├─ 共通マスタ（左）
 │    1. 構成基板数マスター
 │    2. 基板丁数マスター
 │    3. 生産面マスター
 │    4. 新規アカウント登録
 │    5. アカウント管理（管理者のみ）
 ├─ ツール：PDF読み取り（在庫照合。常に押せない）／操作履歴
 └─ ログアウト
```

### 主な業務の流れ

```
① マスターの取り込み（構成基板数・基板丁数・生産面。めったに変えない）
      ↓
② 計画の取り込み（1. 生産計画読込）
      ↓
③ 実績の取り込み・登録（2. 生産実績入力 → 実績CSV取込 → 登録待ち一覧で登録。手入力も可）
      ↓            ↘ ロット進捗チェック・日々の引落一覧で、揃った数・足りない理由を確かめる
④ NG（生産実績入力で申告 → 3. NG・仕損展開で部品に展開して登録）
      ↓
⑤ 集計・帳票（実績レポート → 仕掛数量抽出 → 4. 仕掛部品展開で部品に展開して登録）
      ↓
⑥ 在庫（5. 在庫値入力・6. 理論値入力 → 7. 在庫値出力で差異を出す）
      ↓
⑦ 月の締め・引き継ぎ（新しいデータベースを作成し、前月から未完了分を引き継ぐ。前後にバックアップ）
```

- 共通マスタ（①）はどの月にも共通で、別のファイル（master.db）に入っています。
- 月次データ（②〜⑥）は、月ごとのファイル（db\<フォルダ名>\inventory.db）に入っています。
